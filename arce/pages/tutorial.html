Open Search Tours

Read the four steps below.

  1. Step 1

    Choose a tour

    Select a tour from Search Tours. This example opens Notables Tour 2020.

  2. Step 2

    Select a place

    Choose a name from the place list. This example selects James Hall.

  3. Step 3

    Read the biography

    The place card shows the burial details. Read biography opens the full ARCE biography.

  4. Step 4

    Move between stops

    Use Previous and Next to move through a tour. All places returns to the place list. Collections let you choose individual graves.
